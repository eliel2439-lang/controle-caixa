# Gestão 360° Ultra

Projeto preparado para GitHub e Vercel.

## Estrutura

- `index.html` — aplicação principal completa
- `api/` — funções serverless para integrações futuras
- `package.json` — configuração do projeto
- `package-lock.json` — trava de versão do projeto
- `.gitignore` — arquivos que não devem ir para o GitHub

## Publicar no GitHub

Envie todos os arquivos e pastas deste projeto para a raiz do repositório.

## Publicar no Vercel

1. Importe o repositório do GitHub no Vercel.
2. Framework Preset: `Other`.
3. Root Directory: raiz do repositório.
4. Build Command: deixe vazio ou use `npm run build`.
5. Output Directory: deixe vazio.
6. Faça o deploy.

O `index.html` é a aplicação principal. A pasta `api/` fica pronta para endpoints e integrações futuras.
